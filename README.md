# Mate Perfecto 🧉

Juego web 2D (celu y PC) para cebar el mate perfecto. Bien argento.

- Abrí `index.html` en el navegador (o serví la carpeta con cualquier servidor estático).
- Sin dependencias ni build: Canvas 2D + WebAudio, todo dibujado y sintetizado por código.
- Instalable como app (PWA) cuando se sirve por HTTPS.

**Controles:** elegí una herramienta abajo (Yerba, Azúcar, Peperina, Bombilla, Pava) y mantené apretado / tocá sobre el mate. Tocá a quien espera para pasarle el mate.
Teclado: `1`-`5` herramientas, `Espacio` usar, `F` fuego, `T` tomarlo vos, `V` vaciar, `Esc` pausa.
